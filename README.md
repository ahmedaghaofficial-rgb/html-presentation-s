# 🎬 Syntax Deck — بريزنتيشن بأسلوب Syntax Academy

بريزنتيشنز تعليمية بالعربي: خلفية كحلي، إطار ١٦:٩، ألوان بتتغيّر مع كل فصل، و**رسمة كانفس متحرّكة على كل سلايد — بترسم الفكرة وهي بتتشرح**.

**بريزنتيشن واحد = فيديو واحد.**

---

## إيه اللي في الريبو

| الملف | إيه هو |
|---|---|
| **[`PROMPT.md`](PROMPT.md)** | 🎯 **المنتج.** انسخه والصقه لأي AI — هيسألك «إيه الفكرة؟» وتطلع ببريزنتيشن كامل. |
| **[`sample-slide.html`](sample-slide.html)** | سلايد واحد كامل — HTML + CSS + Canvas في **ملف واحد بلا أي مكتبة**. افتحه في المتصفح على طول. |
| `src/` | نسخة Astro كاملة — ١٠ سلايدات، تنقّل، سبورة حيّة، نوتس تصوير، وضع تصوير. |

---

## ابدأ إزاي

### أسهل طريق — البرومبت

1. افتح [`PROMPT.md`](PROMPT.md) وانسخه كله.
2. الصقه لأي AI (Claude · ChatGPT · Gemini).
3. هيسألك: **إيه الفكرة اللي عايز تعمل عليها بريزنتيشن؟**
4. جاوب — وهيبنيلك.

### تشوف الشكل — السلايد النموذج

افتح `sample-slide.html` في المتصفح. مفيش تنصيب ولا build.

### المشروع الكامل

```bash
npm install
npm run dev      # http://localhost:4340
```

## الكيبورد وانت بتصوّر

| زرار | |
|---|---|
| `←` | السلايد اللي بعده (عربي: الشمال بيقدّم) |
| `→` | السابق |
| `B` | السبورة الحيّة — ارسم فوق أي سلايد |
| `1`–`6` | ألوان الرسم · `E` ممحاة · `Z` رجوع |
| `V` | تعتيم السلايد ورا السبورة |
| `H` | إخفاء شريط السبورة (عشان ميدخلش الكادر) |
| `N` | نوتس التصوير (تحت الكادر) |
| `F` | وضع التصوير — بيشيل كل الواجهة |

---

## تضيف درس جديد

1. لون الفصل في `src/styles/global.css` (`--p-x` + `.slide.part-x` + `.nav-tile.tile-x`).
2. `src/pages/lesson-NN.astro` = `slides[]` + سلايدات جوّه `<Deck>`. مفيش head ولا nav — الـlayout شايلهم.
3. أي رسمة جديدة في `src/components/viz/` مبنية على `@lib/viz` (`fit` + `loop`) — المفروض ~٤٠ سطر.
4. ضيف الدرس في `src/data/lessons.ts`.

> ⚠️ `src/data/lessons.ts` بيستخدمه `Deck.astro` (زرار كل الدروس + سهم قبل/بعد) و`index.astro`. **متمسحوش** — لو الدرس مش موجود فيه، البناء بيقع.
